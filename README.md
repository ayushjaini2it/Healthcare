# Health-Connect

## 🏥 Complete Healthcare Application

A comprehensive healthcare supply chain management system built with vanilla HTML, CSS, and JavaScript. Features complete patient workflow from registration to discharge, including appointment booking with Pune hospitals.

## 🚀 Quick Start

### Option 1: Local Development
1. Clone or download this repository
2. Open `healthcare-app.html` in any modern web browser
3. No installation or build process required

### Option 2: GitHub Pages Deployment
1. Upload `healthcare-app.html` to your GitHub repository
2. Go to Settings → Pages in your GitHub repository
3. Select "Deploy from a branch" and choose `main`
4. Your app will be live at `https://username.github.io/repository-name/`

### Option 3: Netlify/Vercel Deployment
1. Drag and drop `healthcare-app.html` to Netlify/Vercel
2. Get instant live URL

## 🌐 Deployment Issues & Solutions

### Common GitHub Pages Problems

#### Issue 1: CORS Errors with CDN
**Problem**: GitHub Pages may block external CDN requests
**Solution**: Use local assets or GitHub-hosted CDN

#### Issue 2: File Path Issues
**Problem**: Relative paths not working correctly
**Solution**: Use absolute paths or base URL

#### Issue 3: JavaScript Module Loading
**Problem**: ES6 modules not loading properly
**Solution**: Use script tags with proper attributes
